# ScreenPen 屏幕画笔 · 使用说明

一个绿色免安装的屏幕标注工具：**实时画笔 + 区域截图 + 实时缩放 + 标注跟随滚动**。
双击即用，无外部依赖，不写注册表（开机自启除外）。

- 程序文件：`dist\ScreenPen.exe`（230 KB，单文件）
- 配置文件：`dist\ScreenPen.settings.json`（与 EXE 同目录，绿色便携，49 个键）

---

## 一、快速开始

1. 双击 `ScreenPen.exe`。
2. 第一次运行会**自动弹出设置窗口**；之后每次运行会**最小化到托盘**并等待快捷键。
3. 按 `Ctrl + Alt + D` 进入画笔模式，屏幕出现半透明遮罩 + 底部提示条。
4. 按住鼠标左键即可在屏幕上画画。
5. 按 `Esc` 退出画笔模式，回到正常使用。

> **程序已在运行时，再双击一次 `ScreenPen.exe` 会自动弹出设置窗口**（不会启动第二个实例）。
> 找不到托盘图标时，用这个办法最快。

> 托盘图标在右下角通知区域。**右键托盘图标**可以打开设置、截图、退出。

## 二、默认快捷键

### 全局快捷键（任何程序里都能按）

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + D` | 开关画笔（进入/退出标注模式） |
| `Ctrl + Alt + Z` | 实时缩放（放大镜模式） |
| `Ctrl + Alt + S` | **区域截图**并保存（框选） |
| `Ctrl + Alt + C` | **区域截图并复制**到剪贴板（框选） |
| `Ctrl + ↑` / `Ctrl + ↓` | 放大 / 缩小画面 |

**全部快捷键都可以在设置里改**（见第六节）。

### 画笔模式下的按键

| 按键 | 功能 |
| --- | --- |
| `P` / `L` / `R` / `O` / `A` | 切换 **画笔 / 直线 / 矩形 / 椭圆 / 箭头** |
| `T` | **文字标注**（点一下出现输入框；`Enter` 或点击别处**确认**，`Esc` **取消**这次输入） |
| `M` | **马赛克**（拖动涂抹打码） |
| `K` | **聚光灯**（高亮鼠标周围，其余区域压暗） |
| `F` | 开关**跟随滚动**（见第五节） |
| `1` ~ `8` | 直接选择第 1~8 个颜色 |
| `B` | 循环切换颜色 |
| `[` / `]` | 减小 / 增大笔宽 |
| `+` / `-` | 放大 / 缩小画面 |
| `0` | 复位视图（回到 100%、左上角） |
| `Ctrl + Z` | 撤销上一笔 |
| `E` | 清空全部标注 |
| `Ctrl + S` | 保存标注后的截图 |
| `Ctrl + C` | 复制标注图到剪贴板 |
| `Esc` | 退出画笔模式 |

> **工具键是"本地键"不是全局热键**：只有在画笔模式下才生效。
> 这是刻意设计，否则 `P`、`E` 这类单键会抢走你在浏览器/编辑器里的正常输入。

### 按住修饰键临时切换工具

不必先切工具，**按住修饰键直接拖**即可临时使用别的工具：

| 按住 | 临时工具 |
| --- | --- |
| `Ctrl` | 矩形 |
| `Tab` | 椭圆 |
| `Shift` | 直线 |
| `Ctrl + Shift` | 箭头 |

底部提示条会显示当前实际生效的工具（如 `矩形 (Ctrl)`）。
这四项都可以在 设置 → 画笔 里单独关闭。

### 鼠标操作

| 操作 | 功能 |
| --- | --- |
| 左键拖动 | 按当前工具（含修饰键覆盖）绘制 |
| **右键拖动** | 平移画面（不改变缩放比例） |
| **`Ctrl` + 滚轮** | 调整笔宽（始终有效，不受跟随滚动影响） |
| 滚轮 | 跟随滚动开启时滚动下方文档；否则调笔宽 |
| 滚轮（缩放模式） | 缩放画面 |

## 三、实时缩放

按 `Ctrl + Alt + Z` 进入**实时缩放**模式：

- **滚轮**：以鼠标指针为中心放大 / 缩小（0.5× ~ 8×）。画面会以光标位置为锚点，不会跑偏。
- **鼠标碰到屏幕边缘**：画面自动朝该方向移动。
  把光标停在任意一边（上下左右都可以）约 0.2 秒，画面就会持续平移，方便查看屏幕外的内容。
- 底部会显示当前倍率和操作提示。
- 按 `Esc` 退出。

> 画笔模式下也可以用滚轮缩放，用右键拖动平移，这样"边画边看细节"不需要切换模式。

## 四、截图（区域框选）

截图是**框选**的，不再直接截全屏。

### 区域截图并保存 — `Ctrl + Alt + S`

1. 屏幕冻结成一张静态图，出现十字光标。
2. **拖动鼠标框选**要截取的区域。
3. 选好后可以：
   - `Enter` 或点工具条 **保存 (Enter)** → 弹出"保存截图"对话框选路径；
   - **在选区内双击** → 同样直接保存（最快的路径）；
   - `Ctrl + C` 或点 **复制 (Ctrl+C)** → 直接进剪贴板；
   - `Esc` 或点 **取消 (Esc)** → 放弃。
4. 框选后还可以用**方向键**微调选区（按住 `Shift` 每步 10px），`Ctrl + A` 全选。

### 区域截图并复制 — `Ctrl + Alt + C`

同上框选，但**直接复制到剪贴板**，不弹保存对话框。
适合"截一块直接粘到聊天窗口"的场景。

### 截图并标注

1. `Ctrl + Alt + D` 进入画笔模式。
2. 在屏幕上画好标注。
3. 按 `Ctrl + S` → 弹出保存对话框，选择路径保存。
   或按 `Ctrl + C` → 直接复制到剪贴板，可粘贴到聊天窗口、Word 等。

> **注意**：画笔模式下的 `Ctrl + S` / `Ctrl + C` 保存的是
> **"背景 + 你的标注"合成图**，不是单纯的区域框选。

保存时默认弹出**另存为对话框**，可以自由选择保存位置、文件名和格式
（**PNG / JPG / BMP**，默认格式在设置里选）。

如果你在设置里勾选了 *"截图保存到默认文件夹（不弹窗）"*，则会跳过对话框直接保存到指定目录。

### 托盘菜单里的截图项

右键托盘图标还可以直接选：

- **区域截图并保存…**
- **区域截图并复制到剪贴板**
- **整屏截图并保存…**（不框选，直接整屏）
- **复制整屏到剪贴板**

## 五、跟随滚动（在网页 / 文档上标注）

这是给"网页太长、要一边滚一边标注"的场景准备的。

**用法**：画笔模式下按 `F`（托盘会弹出提示"已开启跟随滚动"），
然后滚轮就会**真正滚动下方的网页/文档**，而你画好的标注会**跟着内容一起移动**，
不会漂在原地。

**原理**：程序在后台以低分辨率对比前后两帧画面，算出内容实际移动了多少像素，
再把所有标注平移相同距离。所以**只有画面真的滚动了才会跟随**，静止时不会漂移。

**细节**：

- 跟随滚动**默认关闭**：它需要持续截屏做比对，开启后会略微增加 CPU 占用。
- 光标下没有可滚动的窗口时（例如桌面、全屏视频），`F` 会提示
  *"无法开启跟随滚动"* 并说明原因，滚轮自动回到调整笔宽。
- 静止 20 帧后会自动退出跟随，避免空转。
- `Ctrl + 滚轮` 始终是调笔宽，任何时候都能用。
- 相关的三个设置（常规页）：
  - **允许使用跟随滚动模式**（`ScrollFollowEnabled`）
  - **滚轮滚动网页内容**（`WheelScrollsDocument`，关掉则滚轮改为调笔宽）
  - **让鼠标点击穿透到下方窗口**（`ScrollFollowClickThrough`）

## 六、设置页面

打开方式（任选其一）：

- 双击 EXE 后自动弹出（仅首次 / 手动启动时）
- 右键托盘图标 → **设置…**
- 命令行运行 `ScreenPen.exe --settings`

### 页面说明

| 页面 | 内容 |
| --- | --- |
| **快捷键** | 修改全部快捷键。点击输入框 → 直接按下想要的组合键即可录制。右侧显示 `✓ 可用` 或冲突提示。 |
| **画笔** | 默认笔宽、笔宽上下限、文字大小、马赛克块大小、调色板、线条平滑、**修饰键覆盖开关**、**画笔光标**。 |
| **缩放** | 缩放步进、最小/最大倍率、缩放时是否显示放大镜、边缘移动速度。 |
| **截图** | 图片格式（PNG/JPG/BMP）、是否保存到默认文件夹、默认文件夹路径、是否播放提示音、框选时的压暗与尺寸显示。 |
| **常规** | **开机自动启动**、显示托盘图标、启动时最小化、**跟随滚动**三项。 |
| **关于** | 版本、程序路径、配置文件路径、快捷键速查。 |

底部三个按钮：

- **恢复默认** — 把所有设置还原为出厂值（需再点保存）
- **取消** — 放弃本次修改（不会写入文件）
- **保存设置** — 写入 `ScreenPen.settings.json` 并立即生效

**关于快捷键冲突**：如果新快捷键与系统或其他软件冲突，保存时会提示。
如果只是和**另一项快捷键重复**，会弹确认框——点"是"就照常保存，
**重复的键只有其中一项能用**（列表靠前的那项优先），并且**不会丢弃你其余的修改**。

## 七、画笔光标

画笔模式下，鼠标指针会变成 `assets\画笔.svg` 渲染出的**画笔图标**（白色描边 + 黑色投影，
在深色和浅色背景上都看得清）。

- 开关：设置 → 画笔 → **使用画笔图标作为鼠标指针**
- 大小：设置 → 画笔 → **光标大小**（默认 40px）

> 只有画笔工具显示画笔光标；矩形/椭圆等工具仍用十字光标，方便对准。

## 八、开机自动启动

两种设置方式：

1. **界面**：设置 → 常规 → 勾选 **开机自动启动** → 保存设置。
2. **配置文件**：把 `ScreenPen.settings.json` 里的 `"RunAtStartup"` 改成 `true`。

程序会在每次启动时自动同步注册表，所以改配置文件同样有效。
开机自启会写入：

```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
    值名：ScreenPen
    内容："<EXE完整路径>" --tray
```

只写当前用户，**不需要管理员权限**。取消勾选后会自动删除该项。

> 注意：EXE 移动位置后需要重新勾选一次（或用当前路径重新启动程序一次），
> 因为注册表里记录的是完整路径。

文件位置：**与 EXE 同目录** 的 `ScreenPen.settings.json`

```jsonc
  "ZoomInKey":        "Ctrl+Up",
  "ZoomOutKey":       "Ctrl+Down",

  // ---- 画笔模式下的本地单键 ----
  "ClearKey":         "E",            // 清空标注
  "PenKey":           "P",
  "LineKey":          "L",
  "RectKey":          "R",
  "EllipseKey":       "O",
  "ArrowKey":         "A",

    "#FF3B30", "#FF9500", "#FFCC00", "#34C759",

  "BrushCursorSize":    40,

  // ---- 缩放 ----
  "ZoomStepPercent":  25,             // 每格滚轮缩放百分比
  "MinZoom":          0.5,
  "MaxZoom":          8,
  "MagnifierDuringLiveZoom": true,

  // ---- 截图 ----
  "ScreenshotFormat": "png",          // png/jpg/bmp
  "SaveScreenshotsToDefaultFolder": false,   // true=不弹窗

  "PlaySoundOnScreenshot": false,
  "RegionDimOutside":  true,          // 框选时选区外压暗
  "RegionShowSize":    true,          // 框选时显示尺寸

  // ---- 跟随滚动 ----
  "ScrollFollowEnabled":        true, // 允许 F 键开启跟随滚动
  "WheelScrollsDocument":       true, // 滚轮滚动网页（false=调笔宽）
  "ScrollFollowClickThrough":   true, // 鼠标点击穿透到下方窗口

  // ---- 常规 ----
  "RunAtStartup":     false,
  "ShowTrayIcon":     true,
  "StartMinimized":   false
}
```

> 配置文件损坏或格式错误时，程序会自动回退到默认设置，**不会崩溃**。
> 想恢复出厂设置，直接删除该文件即可。

全局快捷键写法：`Ctrl+Alt+D`、`Shift+F1`、`Ctrl+Shift+S`、`Alt+1` 等，
**必须包含至少一个修饰键**（Ctrl / Alt / Shift）。
`ClearKey`、`PenKey` 等单键项则是**不带修饰键的单个字母**。

## 十、多显示器与高 DPI

- 程序声明为 **Per-Monitor DPI Aware V2**，在 4K / 缩放 125%、150%、200% 的屏幕上
  坐标**不会错位**，设置界面也会按当前 DPI 等比放大。
- 标注覆盖**整个虚拟桌面**（所有显示器拼接范围），可以跨屏画线。
- 截图截取的是整个虚拟桌面，然后在上面框选。

## 十二、常见问题

**Q：按快捷键没反应？**
1. 确认程序在运行（看托盘图标）。
2. 快捷键可能被其他软件占用。打开设置 → 快捷键，看右侧是否显示 `✓ 可用`；显示冲突就换一个组合。
3. 如果是以管理员身份运行的窗口（如任务管理器）在前台，普通权限的 ScreenPen 收不到全局快捷键——这是 Windows 的限制。

**Q：为什么按 `P`、`E` 这些键没反应？**
它们是**画笔模式下的本地键**，只有 `Ctrl+Alt+D` 进入标注模式后才生效（见第二节）。

**Q：画完的标注怎么保存？**
画笔模式下按 `Ctrl + S` 选路径保存，或 `Ctrl + C` 复制到剪贴板。

**Q：截图能不能只截一块？**
可以。`Ctrl + Alt + S` 是框选后保存，`Ctrl + Alt + C` 是框选后直接复制（见第四节）。

**Q：按 `F` 说"无法开启跟随滚动"？**
说明光标下没有可滚动的窗口（桌面、全屏视频、图片查看器等）。
把光标移到网页或文档上再按 `F`。另外跟随滚动需要先在设置 → 常规里勾选"允许使用跟随滚动模式"。

**Q：跟随滚动开着但标注没动？**
只有**画面内容真的滚动了**才会跟随（程序靠比对两帧画面判断）。
如果滚轮没有传到下层窗口，检查 设置 → 常规 → "滚轮滚动网页内容"是否被关掉了。

**Q：怎么退出程序？**
右键托盘图标 → **退出**。直接关窗口只会退出当前模式，程序仍留在托盘。

**Q：第二台显示器上没有遮罩？**
确认是按 `Ctrl+Alt+D` 进入的画笔模式；遮罩覆盖整个虚拟桌面，若显示器是"扩展"模式应该全部覆盖。若使用"仅第二屏幕"复制模式，则属于同一桌面。

**Q：想改默认颜色？**
设置 → 画笔 → 调色板，点色块修改，可增删。1~8 数字键对应调色板顺序。

**Q：EXE 能拷到别的电脑用吗？**
可以。单文件绿色版，拷过去双击即可（需要 .NET Framework 4.x，Windows 7 以上系统自带或可免费安装）。

```powershell
cd ScreenPen
```
