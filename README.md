# ScreenPen 屏幕画笔 · 使用说明

一个绿色免安装的屏幕标注工具：**实时画笔 + 区域/窗口截图 + 桌面贴图 + 实时缩放 + 屏幕取色 +
标注跟随滚动 + 截图美化**。
双击即用，无外部依赖，不写注册表（开机自启除外）。

- 程序文件：`dist\ScreenPen.exe`（265 KB，单文件）
- 配置文件：`dist\ScreenPen.settings.json`（与 EXE 同目录，绿色便携，66 个键）

**标注工具**：画笔、直线、矩形、椭圆、箭头（直/弧/折三种样式）、文字、马赛克、聚光灯、
荧光笔、序号标记 —— 全部支持多级撤销 / 重做。

---

## 一、快速开始

1. 双击 `ScreenPen.exe`。
2. 第一次运行会**自动弹出设置窗口**；之后每次运行会**最小化到托盘**并等待快捷键。
3. 按 `Ctrl + Alt + D` 进入画笔模式，屏幕出现半透明遮罩 + 底部提示条。
4. 按住鼠标左键即可在屏幕上画画。
5. 按 `Esc` 退出画笔模式，回到正常使用。

> **程序已在运行时，再双击一次 `ScreenPen.exe` 会自动弹出设置窗口**（不会启动第二个实例）。
> 找不到托盘图标时，用这个办法最快。

> 托盘图标在右下角通知区域。**右键托盘图标**可以打开设置、截图、退出。

## 二、默认快捷键

### 全局快捷键（任何程序里都能按）

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + Alt + D` | 开关画笔（进入/退出标注模式） |
| `Ctrl + Alt + Z` | 实时缩放（放大镜模式） |
| `Ctrl + Alt + S` | **区域截图**并保存（框选） |
| `Ctrl + Alt + C` | **区域截图并复制**到剪贴板（框选） |
| `Ctrl + Alt + W` | **窗口截图**（直接截取鼠标所在的那个窗口，不用框选） |
| `Ctrl + Alt + P` | **屏幕取色器**（放大镜取色，取完自动复制色号） |
| `Ctrl + ↑` / `Ctrl + ↓` | 放大 / 缩小画面 |

**全部快捷键都可以在设置里改**（见第六节）。

### 画笔模式下的按键

| 按键 | 功能 |
| --- | --- |
| `P` / `L` / `R` / `O` / `A` | 切换 **画笔 / 直线 / 矩形 / 椭圆 / 箭头** |
| `T` | **文字标注**（点一下出现输入框；`Enter` 或点击别处**确认**，`Esc` **取消**这次输入） |
| `M` | **马赛克**（拖动涂抹打码） |
| `K` | **聚光灯**（高亮鼠标周围，其余区域压暗） |
| `H` | **荧光笔**（半透明宽笔画，不会遮住底下的字） |
| `N` | **序号标记**（每点一下画一个带数字的圆点，自动递增） |
| `F` | 开关**跟随滚动**（见第五节） |
| `1` ~ `8` | 直接选择第 1~8 个颜色 |
| `B` | 循环切换颜色 |
| `[` / `]` | 减小 / 增大笔宽 |
| `+` / `-` | 放大 / 缩小画面 |
| `0` | 复位视图（回到 100%、左上角） |
| `Ctrl + Z` | 撤销上一笔 |
| `Ctrl + Y` | **重做**（恢复刚被撤销的标注，`Ctrl + Shift + Z` 同样有效） |
| `E` | 清空全部标注 |
| `Ctrl + S` | 保存标注后的截图 |
| `Ctrl + C` | 复制标注图到剪贴板 |
| `Esc` | 退出画笔模式 |

> **工具键是"本地键"不是全局热键**：只有在画笔模式下才生效。
> 这是刻意设计，否则 `P`、`E` 这类单键会抢走你在浏览器/编辑器里的正常输入。

> **打字时这些单键会让路**：`T` 打开输入框之后，`L`、`P`、`O`、`E`、`A`、`B`、`M`、`R`、`H`、`N`、`1`~`8`
> 等等都**只会被正常输入到文字里**，不会中途切工具或清空画布。
> `Enter` / `Esc` 仍然有效：前者确认这次标注，后者放弃这次标注。
> （旧版本这里有个 bug——按下 `T` 打字时敲到 `L`、`P`、`O`、`E`、`A` 会触发对应命令，
> 导致输入框直接无法继续输入；现已修复。）

### 按住修饰键临时切换工具

不必先切工具，**按住修饰键直接拖**即可临时使用别的工具：

| 按住 | 临时工具 |
| --- | --- |
| `Ctrl` | 矩形 |
| `Tab` | 椭圆 |
| `Shift` | 直线 |
| `Ctrl + Shift` | 箭头 |

底部提示条会显示当前实际生效的工具（如 `矩形 (Ctrl)`）。
这四项都可以在 设置 → 画笔 里单独关闭。

### 鼠标操作

| 操作 | 功能 |
| --- | --- |
| 左键拖动 | 按当前工具（含修饰键覆盖）绘制 |
| **右键拖动** | 平移画面（不改变缩放比例） |
| **`Ctrl` + 滚轮** | 调整笔宽（始终有效，不受跟随滚动影响） |
| 滚轮 | 跟随滚动开启时滚动下方文档；否则调笔宽 |
| 滚轮（缩放模式） | 缩放画面 |

### 荧光笔 — `H`

半透明的宽笔画，**不会遮住底下的文字**，适合在截图或文档上划重点。

- `H` 切到荧光笔，然后拖动即可。笔画是画笔样式的加粗版，颜色跟当前调色板一致。
- 透明度在 设置 → 画笔 → 「荧光笔与序号」 里调（`HighlighterAlpha`，默认 90，范围 16~220）。
  调小更透、调大更实。
- 和其它工具一样受 `[` / `]` 笔宽控制。
- 它自己独立保存透明度，**不会影响**普通画笔、直线、箭头的颜色表现。

### 序号标记 — `N`

每点一下画一个**带数字的圆点**，数字自动递增，适合写"第一步/第二步"这种操作说明。

- `N` 切到序号工具，在要标注的位置点一下即可。
- 圆点大小在 设置 → 画笔 → 「荧光笔与序号」 里调（`StepBadgeSize`，默认 34）。
- **一张截图内数字不重复**：撤销掉最后一个序号后，下一个序号会**重新用回**那个数字；
  删掉中间某个序号，剩下的会重新编号。因此导出的图里永远不会有重号或跳号。
- `StepNumberPersistent`（默认开启）控制**跨截图**的连续性：
  - 开启时，退出再进画笔模式，序号会**接着上一张图的最大数字**往下走，
    适合做连续多张的步骤图；
  - 关闭时，每次进入画笔模式都从 1 开始。

### 箭头样式

在 设置 → 画笔 → 「荧光笔与序号」 里可以切换三种箭头：

| 样式 | 效果 |
| --- | --- |
| 直线箭头 | 普通直线箭头（默认） |
| 弧线箭头 | 带弧度的箭头，适合画流程回环 |
| 折线箭头 | 拐一个直角的箭头，适合画线框之间的连线 |

### 撤销与重做

- `Ctrl + Z` 撤销，`Ctrl + Y`（或 `Ctrl + Shift + Z`）重做。
- 两条栈各自最多保留 **200 步**。
- **贴图（钉住的图）不参与撤销**：它自带一张位图，撤销语义不明确，所以被刻意排除在历史之外。
  想删掉贴图，直接用它的关闭按钮。
- `E` 清空画布会同时丢弃重做栈（这是有意的：清空之后"重做"回到一个已经被清掉的画面没有意义）。

## 三、实时缩放

按 `Ctrl + Alt + Z` 进入**实时缩放**模式：

- **滚轮**：以鼠标指针为中心放大 / 缩小（0.5× ~ 8×）。画面会以光标位置为锚点，不会跑偏。
- **鼠标碰到屏幕边缘**：画面自动朝该方向移动。
  把光标停在任意一边（上下左右都可以）约 0.2 秒，画面就会持续平移，方便查看屏幕外的内容。
- 底部会显示当前倍率和操作提示。
- 按 `Esc` 退出。

> 画笔模式下也可以用滚轮缩放，用右键拖动平移，这样"边画边看细节"不需要切换模式。

## 四、截图（区域框选）

截图是**框选**的，不再直接截全屏。

### 区域截图并保存 — `Ctrl + Alt + S`

1. 屏幕冻结成一张静态图，出现十字光标。
2. **拖动鼠标框选**要截取的区域。
3. 选好后可以：
   - `Enter` 或点工具条 **保存 (Enter)** → 弹出"保存截图"对话框选路径；
   - **在选区内双击** → 等同按 `Enter`，直接执行默认动作（保存时不再需要点按钮）；
   - `Ctrl + C` 或点 **复制 (Ctrl+C)** → 直接进剪贴板；
   - `P` 或点 **贴图 (P)** → 把选区**钉在桌面上**（见下面"贴图"一节）；
   - `Esc` 或点 **取消 (Esc)** → 放弃。
4. 框选后还可以用**方向键**微调选区（按住 `Shift` 每步 10px），`Ctrl + A` 全选。

> 工具条上的四个按钮是 **保存 / 复制 / 贴图 / 取消**。其中被高亮（橙色）的那个
> 就是 `Enter` 会执行的动作——用 `Ctrl+Alt+S` 进来时是**保存**，用 `Ctrl+Alt+C` 进来时是**复制**，
> 从托盘"区域截图并钉在桌面"进来时是**贴图**。宽度不够时按钮会自动用短标签或整体收窄。

### 区域截图并复制 — `Ctrl + Alt + C`

同上框选，但**直接复制到剪贴板**，不弹保存对话框。
适合"截一块直接粘到聊天窗口"的场景。

### 窗口截图 — `Ctrl + Alt + W`

**不用框选**，直接截下鼠标所指的那**整个窗口**（含标题栏和边框）。

1. 把鼠标移到目标窗口上，按 `Ctrl + Alt + W`。
2. ScreenPen 会识别光标下的**顶层窗口**并截取它，然后进入标注/保存流程。

细节：

- 边界取自 Windows 的 **DWM 扩展边框**（`DWMWA_EXTENDED_FRAME_BOUNDS`）而不是 `GetWindowRect`。
  这一点很关键：`GetWindowRect` 返回的是**被 DPI 虚拟化过**的坐标，还包含窗口周围一圈
  不可见的拉伸边框，在高 DPI 屏上会截歪、截多。用 DWM 的真实边界才能正好套住窗口。
- **不会截到 ScreenPen 自己**：设置窗口、托盘、贴图等自身窗口都在排除名单里，
  所以对着自己的窗口按是不会截出一张"截图里的截图"的。
- 最小化的窗口、不可见的窗口会被自动跳过，会继续往下找光标下可截的窗口。

### 屏幕取色器 — `Ctrl + Alt + P`

取屏幕上任意一点的颜色，不需要先截图。

1. 按 `Ctrl + Alt + P`，屏幕冻结，鼠标旁边出现**放大镜**。
2. 移动鼠标找像素，`左键点击` **确认取色**。
3. `右键` 或 `Esc` **取消**。

取到之后：

- 颜色会**替换调色板里当前选中的那一格**；
- 色号（`#RRGGBB`）会**自动复制到剪贴板**，可以直接粘到 CSS / 设计稿里。

放大镜的大小和倍率在 设置 → 截图 → 「屏幕取色器」 里调
（`PickerLoupeSize` 默认 150，`PickerZoom` 默认 8×）。

### 贴图：把截图钉在桌面上

把截下来的内容变成一张**浮在桌面最上层的图片窗口**（类似 Snipaste 的贴图），
用来对照、临摹、比数据都很方便。

**怎么贴出一张图**（三种入口，都走同一个框选界面）：

1. 从托盘菜单 **区域截图并钉在桌面** → 框选，按 `Enter`；
2. 任意框选界面里选中区域后按 `P`，或点工具条上的 **贴图 (P)**；
3. 想贴整屏也行：框选时按 `Ctrl + A` 全选，再按 `P`。

> 贴图**不会**写文件、也**不会**占用剪贴板——它只在自己进程里显示。
> 和画笔模式下的 `Ctrl+S` / `Ctrl+C` 完全独立。

**贴图窗口的操作**：

| 操作 | 功能 |
| --- | --- |
| **左键拖动** | 移动贴图到任意位置 |
| **滚轮** | 以光标位置为锚点缩放（每格约 ×1.12，范围 0.1× ~ 8×） |
| **鼠标移入** | 右上角出现关闭按钮 `✕`，点一下关闭 |
| **右键单击** | 直接关闭这张贴图 |
| `Esc` | 关闭（贴图窗口需要有焦点） |
| `Ctrl + C` | 复制这张贴图的原始像素到剪贴板 |
| `Ctrl + S` | 另存为文件（PNG / JPG / BMP，默认文件名 `ScreenPen_Pin_年月日_时分秒.png`） |

**细节**：

- 贴图**始终置顶**，不会被普通窗口盖住；它不出现在任务栏里。
- 可以同时贴**任意多张**，各自独立拖动、缩放、关闭，互不影响。
- 缩放是**按原图尺寸重算**的，所以放大缩小多少次都不会越缩越糊、也不会累积误差；
  窗口尺寸和位置都会被夹在工作区内，**至少保证 40px 留在屏幕上**，拖不丢。
- 缩放后 `Ctrl + C` / `Ctrl + S` 拿到的仍是**原始分辨率的像素**，不是屏幕上那块放大后的模糊图。
- 退出 ScreenPen 时（托盘 → 退出）**所有贴图会一起关闭**，不会留在桌面上。

> 如果 `Ctrl + C` 提示"复制失败"，多半是剪贴板正被别的程序占用，过一会儿再试即可。

### 截图并标注

1. `Ctrl + Alt + D` 进入画笔模式。
2. 在屏幕上画好标注。
3. 按 `Ctrl + S` → 弹出保存对话框，选择路径保存。
   或按 `Ctrl + C` → 直接复制到剪贴板，可粘贴到聊天窗口、Word 等。

> **注意**：画笔模式下的 `Ctrl + S` / `Ctrl + C` 保存的是
> **"背景 + 你的标注"合成图**，不是单纯的区域框选。

保存时默认弹出**另存为对话框**，可以自由选择保存位置、文件名和格式
（**PNG / JPG / BMP**，默认格式在设置里选）。

如果你在设置里勾选了 *"截图保存到默认文件夹（不弹窗）"*，则会跳过对话框直接保存到指定目录。

### 美化截图（保存时自动加背景和阴影）

在 设置 → 截图 → 「美化截图」 里勾选 *保存时自动美化* 之后，
**保存出去的图片**会自动套上一圈渐变背景、圆角和柔和阴影，
看起来像社交平台上那种"截图卡片"，可以直接发聊天窗口或贴进文档。

| 选项 | 说明 |
| --- | --- |
| 保存时自动美化 | 总开关（默认关闭） |
| 内边距 | 圆角图片四周留出的背景宽度，默认 48px，范围 0~400 |
| 圆角 | 图片本身的圆角半径，默认 16px，范围 0~200；会自动夹到不超过图片短边的一半 |
| 柔化阴影 | 是否在图片下面叠一层柔和的投影（默认开） |
| 背景色 1 / 背景色 2 | 背景是这两个颜色之间的 **45° 渐变**，可以点色块直接开取色器挑，也可以按"对调"交换两端 |

**重要：美化只影响"存到磁盘的文件"，不影响剪贴板和贴图。**

- `Ctrl + C` 复制到剪贴板的仍然是**未美化的原始合成图**（贴到编辑器里不会莫名多一圈背景）。
- 贴图也一样，用的是原始像素。
- 原因很直接：美化后的图**尺寸会变大**（四周多了背景），
  如果连剪贴板一起改，粘进文档时尺寸对不上会很别扭。想发美化版就存文件。

另外，美化后的图**缩放不会丢质量**：渐变背景和阴影都是实时按目标尺寸重算的，
不是先把小图放大再贴上去。

### 托盘菜单里的截图项

右键托盘图标还可以直接选：

- **区域截图并保存…**
- **区域截图并复制到剪贴板**
- **区域截图并钉在桌面**（框选后贴成桌面浮图）
- **整屏截图并保存…**（不框选，直接整屏）
- **复制整屏到剪贴板**

## 五、跟随滚动（在网页 / 文档上标注）

这是给"网页太长、要一边滚一边标注"的场景准备的。

**用法**：画笔模式下按 `F`（托盘会弹出提示"已开启跟随滚动"），
然后滚轮就会**真正滚动下方的网页/文档**，而你画好的标注会**跟着内容一起移动**，
不会漂在原地。

**原理**：程序在后台以低分辨率对比前后两帧画面，算出内容实际移动了多少像素，
再把所有标注平移相同距离。所以**只有画面真的滚动了才会跟随**，静止时不会漂移。

**细节**：

- 跟随滚动**默认关闭**：它需要持续截屏做比对，开启后会略微增加 CPU 占用。
- 光标下没有可滚动的窗口时（例如桌面、全屏视频），`F` 会提示
  *"无法开启跟随滚动"* 并说明原因，滚轮自动回到调整笔宽。
- 静止 20 帧后会自动退出跟随，避免空转。
- `Ctrl + 滚轮` 始终是调笔宽，任何时候都能用。
- 相关的三个设置（常规页）：
  - **允许使用跟随滚动模式**（`ScrollFollowEnabled`）
  - **滚轮滚动网页内容**（`WheelScrollsDocument`，关掉则滚轮改为调笔宽）
  - **让鼠标点击穿透到下方窗口**（`ScrollFollowClickThrough`）

## 六、设置页面

打开方式（任选其一）：

- 双击 EXE 后自动弹出（仅首次 / 手动启动时）
- 右键托盘图标 → **设置…**
- 命令行运行 `ScreenPen.exe --settings`

### 页面说明

| 页面 | 内容 |
| --- | --- |
| **快捷键** | 修改全部快捷键。点击输入框 → 直接按下想要的组合键即可录制。右侧显示 `✓ 可用` 或冲突提示。 |
| **画笔** | 默认笔宽、笔宽上下限、文字大小、马赛克块大小、调色板、线条平滑、**修饰键覆盖开关**、**画笔光标**、**荧光笔透明度 / 箭头样式 / 序号圆点大小 / 序号跨图连续**。 |
| **缩放** | 缩放步进、最小/最大倍率、缩放时是否显示放大镜、边缘移动速度。 |
| **截图** | 图片格式（PNG/JPG/BMP）、是否保存到默认文件夹、默认文件夹路径、是否播放提示音、框选时的压暗与尺寸显示、**美化截图（背景/圆角/阴影/渐变色）**、**屏幕取色器（放大镜大小与倍率）**。 |
| **常规** | **开机自动启动**、显示托盘图标、启动时最小化、**跟随滚动**三项。 |
| **关于** | 版本、程序路径、配置文件路径、快捷键速查。 |

底部三个按钮：

- **恢复默认** — 把所有设置还原为出厂值（需再点保存）
- **取消** — 放弃本次修改（不会写入文件）
- **保存设置** — 写入 `ScreenPen.settings.json` 并立即生效

**窗口大小可以自己调**：

- 设置窗口现在是**可调整大小**的：拖边框、拖角都可以，右上角还有**最大化**和**最小化**按钮。
- 拉大窗口只是多出背景空白，**卡片和控件不会被拉伸变形**；底部的三个按钮会自动贴到新的右下角，
  左侧的页面列表和内容区高度也会跟着变，需要时出现滚动条。
- 窗口有大小下限（约 560 × 460 逻辑像素，按当前 DPI 换算），再往里拖就停住了，
  所以按钮不会被挤出可视区域。
- 窗口里显示的字号跟随系统 DPI，不随窗口大小变化——把窗口调大**不会**让字变大。

**关于快捷键冲突**：如果新快捷键与系统或其他软件冲突，保存时会提示。
如果只是和**另一项快捷键重复**，会弹确认框——点"是"就照常保存，
**重复的键只有其中一项能用**（列表靠前的那项优先），并且**不会丢弃你其余的修改**。

> 保存失败时会明确提示 **"设置保存失败"**（例如安装目录只读、磁盘满），
> 此时本次改动只在当前这次运行里有效，重启后会回到旧值。
> 保存本身是**原子写入**的：写配置文件的过程中断电或崩溃，也不会把原配置弄丢或写坏。

## 八、开机自动启动

两种设置方式：

1. **界面**：设置 → 常规 → 勾选 **开机自动启动** → 保存设置。
2. **配置文件**：把 `ScreenPen.settings.json` 里的 `"RunAtStartup"` 改成 `true`。

程序会在每次启动时自动同步注册表，所以改配置文件同样有效。
开机自启会写入：

```
HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run
    值名：ScreenPen
    内容："<EXE完整路径>" --tray
```

只写当前用户，**不需要管理员权限**。取消勾选后会自动删除该项。

> 注意：EXE 移动位置后需要重新勾选一次（或用当前路径重新启动程序一次），
> 因为注册表里记录的是完整路径。

## 十二、常见问题

**Q：按快捷键没反应？**
1. 确认程序在运行（看托盘图标）。
2. 快捷键可能被其他软件占用。打开设置 → 快捷键，看右侧是否显示 `✓ 可用`；显示冲突就换一个组合。
3. 如果是以管理员身份运行的窗口（如任务管理器）在前台，普通权限的 ScreenPen 收不到全局快捷键——这是 Windows 的限制。

**Q：为什么按 `P`、`E` 这些键没反应？**
它们是**画笔模式下的本地键**，只有 `Ctrl+Alt+D` 进入标注模式后才生效（见第二节）。

**Q：用 `T` 打字时，一敲到 `L`、`P`、`O`、`E`、`A` 就打不了字了？**
这是旧版本的 bug，**现已修复**。原因是输入框出现时这些单键命令仍会先一步截走按键。
现在只要文字输入框是打开的，所有单键命令都会让路，`Enter` 确认、`Esc` 放弃照常可用（见第二节）。

**Q：画完的标注怎么保存？**
画笔模式下按 `Ctrl + S` 选路径保存，或 `Ctrl + C` 复制到剪贴板。

**Q：截图能不能只截一块？**
可以。`Ctrl + Alt + S` 是框选后保存，`Ctrl + Alt + C` 是框选后直接复制（见第四节）。

**Q：怎么把截图贴在桌面上？**
托盘菜单 → **区域截图并钉在桌面**；或在框选时按 `P` / 点 **贴图 (P)**。
贴出来的图可以拖动、滚轮缩放、`Ctrl+C` 复制、`Ctrl+S` 另存、`Esc` 或右键关闭（见第四节"贴图"）。

**Q：贴图会不会挡住别的窗口 / 退出后还在？**
贴图**始终置顶**（这是它存在的意义）；右键托盘 → **退出** 时所有贴图会**一起关闭**，
不会留在桌面上，也不会残留进程。

**Q：设置窗口太小 / 想放大？**
直接拖边框或点最大化即可，设置窗口已经可以自由调整大小（见第六节）。
拉大只会多出空白，不会把内容拉变形。

**Q：按 `F` 说"无法开启跟随滚动"？**
说明光标下没有可滚动的窗口（桌面、全屏视频、图片查看器等）。
把光标移到网页或文档上再按 `F`。另外跟随滚动需要先在设置 → 常规里勾选"允许使用跟随滚动模式"。

**Q：跟随滚动开着但标注没动？**
只有**画面内容真的滚动了**才会跟随（程序靠比对两帧画面判断）。
如果滚轮没有传到下层窗口，检查 设置 → 常规 → "滚轮滚动网页内容"是否被关掉了。

**Q：怎么退出程序？**
右键托盘图标 → **退出**。直接关窗口只会退出当前模式，程序仍留在托盘。

**Q：第二台显示器上没有遮罩？**
确认是按 `Ctrl+Alt+D` 进入的画笔模式；遮罩覆盖整个虚拟桌面，若显示器是"扩展"模式应该全部覆盖。若使用"仅第二屏幕"复制模式，则属于同一桌面。

**Q：想改默认颜色？**
设置 → 画笔 → 调色板，点色块修改，可增删。1~8 数字键对应调色板顺序。

**Q：EXE 能拷到别的电脑用吗？**
可以。单文件绿色版，拷过去双击即可（需要 .NET Framework 4.x，Windows 7 以上系统自带或可免费安装）。
